# Dictionnaire des données (synthétiques)

| Champ | Signification |
| --- | --- |
| loan_id | Identifiant fictif unique |
| loan_type | Type de prêt simulé : Mortgage, Consumer, Auto, SME |
| exposure_eur | Exposition simulée en euros |
| dti | Ratio dette / revenu simulé |
| credit_score | Score artificiel entre 300 et 850 |
| default_90d | Indicateur d'incident fictif à 90 jours (0 ou 1) |

Les variables sont générées artificiellement. Aucun modèle bancaire réel ni donnée de client n'est utilisé.
